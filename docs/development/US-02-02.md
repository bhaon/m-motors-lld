# US-02-02 - Connexion client à l'espace personnel

## Objectif
Mettre en place la connexion client pour permettre l'accès à l'espace personnel (dossiers et contrats).

## Implémentation réalisée

### Backend
- Ajout de `LoginRequest`, `LoginResponse` et `CurrentUserResponse` dans `backend/app/schemas/auth.py`.
- Ajout de l'endpoint `POST /api/v1/auth/login` dans `backend/app/api/v1/endpoints/auth.py`.
- Ajout de l'endpoint `GET /api/v1/auth/me` pour valider la session via cookie JWT.
- Authentification par `email` + `password` avec `verify_password(...)`.
- Génération d'un JWT via `create_access_token(...)`.
- Stockage du JWT dans un cookie `access_token`:
  - `HttpOnly=true`
  - `SameSite=lax`
  - `Path=/`
  - `Max-Age` aligné sur `ACCESS_TOKEN_EXPIRE_MINUTES`
  - `Secure` activé si `FRONTEND_BASE_URL` est en HTTPS.
- Retour d'un message d'erreur générique en cas d'échec: `Email ou mot de passe invalide.`

### Frontend
- Création de la page de connexion: `frontend/src/app/connexion/page.tsx`.
- Formulaire email/mot de passe avec appel `POST /api/v1/auth/login` (`credentials: include`).
- Affichage d'un message d'erreur générique en cas d'échec.
- Redirection vers `/espace-client` après succès.
- Création de la page cible `frontend/src/app/espace-client/page.tsx`.
- Vérification serveur de la session dans `/espace-client` via `GET /api/v1/auth/me` et redirection vers `/connexion` si non authentifié.
- Ajout du lien `Connexion` dans `frontend/src/components/Navbar.tsx`.
