# US-03-01 - Dépôt initial d'un dossier Achat / LLD depuis la fiche véhicule

## Objectif

Permettre à un client authentifié d'initier en ligne un dossier d'achat ou de LLD depuis la fiche détaillée d'un véhicule.

## Parcours utilisateur

1. Le client ouvre la fiche d'un véhicule depuis le catalogue.
2. Il clique sur `Déposer un dossier Achat` ou `Déposer un dossier LLD`.
3. Une modale de confirmation s'affiche avant toute création.
4. Si le client annule (bouton, `Echap` ou clic en dehors), aucun dossier n'est créé.
5. Si le client confirme, le frontend appelle l'API avec le type correspondant.
6. Le backend crée un dossier avec une référence lisible unique (format `DOS-YYYY-00001`).

## Implémentation technique

### Backend

- Nouveau schéma API `dossier.py` :
  - `DossierCreateIn` (`vehicle_id`, `type`)
  - `DossierCreateOut` (id, référence, type, statut, véhicule, client)
- Nouveau endpoint : `POST /api/v1/dossiers`
  - authentification via cookie HTTP-only `access_token`
  - vérification de l'existence du véhicule catalogue
  - blocage d'un dossier `lld` si le véhicule n'est pas compatible LLD
  - génération d'une référence unique lisible `DOS-YYYY-00001`
- Enregistrement du dossier avec statut initial `brouillon`

### Frontend

- `CataloguePage` :
  - ouverture d'une modale de confirmation au clic sur les CTA de la fiche véhicule
  - annulation possible sans effet (bouton annuler, `Echap`, clic extérieur)
  - appel `POST /api/v1/dossiers` uniquement après confirmation explicite
  - affichage d'un retour utilisateur avec la référence créée

## Critères DoD couverts

- Boutons `Déposer un dossier Achat` et `Déposer un dossier LLD` distincts sur la fiche véhicule : oui.
- Dossier créé avec une référence unique lisible : oui (`DOS-YYYY-00001`).
- Type de dossier transmis selon le bouton cliqué : oui (`achat` / `lld`).
- Création uniquement après validation explicite du client : oui.
- Annulation du dépôt au clic extérieur de la modale : oui (aucun dossier créé).

## Tests ajoutés

### Backend unitaires

- création dossier achat + référence unique sur deux créations successives
- rejet d'un dossier LLD sur véhicule non éligible
- rejet sans authentification

### Frontend composants / pages

- ouverture de la modale de confirmation puis création LLD après validation
- affichage d'un message d'erreur en cas d'échec API
- annulation au clic extérieur sans création de dossier
- création achat après confirmation
