# US-02-04 - Gestion du profil client

## Objectif
Permettre au client de maintenir à jour ses informations personnelles (profil, email, mot de passe).

## Implémentation réalisée

### Backend
- Ajout des schémas `UpdateProfileRequest`, `UpdateProfileResponse`, `ChangePasswordRequest`, `ChangePasswordResponse` et enrichissement de `CurrentUserResponse`.
- Ajout de `PUT /api/v1/auth/profile` :
  - modifie `first_name`, `last_name`, `phone`, `email`
  - en cas de changement d'email :
    - invalide la validation email (`email_verified=false`)
    - génère un nouveau token de validation
    - envoie un lien de revalidation par email.
- Ajout de `POST /api/v1/auth/change-password` :
  - exige `old_password`
  - vérifie l'ancien mot de passe avant de hasher/enregistrer le nouveau.
- `GET /api/v1/auth/me` renvoie désormais les champs de profil nécessaires à l'UI.

### Frontend
- Création du composant `frontend/src/app/espace-client/ProfileManagementClient.tsx` :
  - formulaire profil (prénom, nom, téléphone, email)
  - formulaire changement de mot de passe (ancien + nouveau)
  - confirmations visuelles succès/erreur.
- `frontend/src/app/espace-client/page.tsx` :
  - garde serveur de session via `/api/v1/auth/me`
  - injection des données utilisateur dans le composant de gestion de profil.
